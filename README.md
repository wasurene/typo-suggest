# Подсказка при опечатке в названии

Автор: Усов Константин Андреевич

## Пользователь и задача
Человек ищет товар в небольшом локальном справочнике и при опечатке хочет увидеть близкие названия с расстоянием редактирования.

## Вход 
- `words.txt` - до 100 слов, по одному на строку, длина до 30 символов.
- Параметры запуска: `-query` (запрос), `-max` (порог расстояния), `-input` (файл словаря), `-output` (файл результата).

## Выход
Кандидаты с расстоянием не больше порога, отсортированные по расстоянию, затем по названию. Вывод на экран и в файл.

## Алгоритм
Самостоятельный расчет расстояния редактирования (вставка, удаление, замена) через таблицу динамического программирования. 
Готовая функция расстояния не используется.

## Ограничения
- без фонетики
- перестановка символов не считается отдельной операцией
- точное совпадение имеет расстояние 0 и идет первым

## Запуск

```bash
go run . -query "кот" -max 1 -input data/words.txt -output out.txt
```
